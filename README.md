# Урок 3: Bash-скрипт для встановлення DevOps інструментів

Цей міні-проєкт містить Bash-скрипт `install_dev_tools.sh`, який автоматизує встановлення базового набору інструментів для роботи з DevOps. Скрипт призначений для операційних систем на базі Ubuntu/Debian.

## Що встановлює скрипт:
1. **Docker** (включаючи `docker-ce`, `docker-ce-cli`, `containerd.io`, `docker-buildx-plugin`)
2. **Docker Compose Plugin** (встановлюється плагін для docker-cli)
3. **Python 3** (включаючи `python3-pip` та `python3-venv`)
4. **Django** (через утиліту `pip3`)

> 💡 **Особливість:** Скрипт розумний і перевіряє наявність кожного інструменту перед його встановленням. Якщо Docker чи Python вже присутні в системі, він просто повідомить про це і перейде до наступного кроку.

### 🐧 Механізм адаптації до ОС:
Скрипт автоматично визначає операційну систему вашого комп'ютера за допомогою читання системного файлу `/etc/os-release`.
- **Для Ubuntu та Debian:** використовується звичний пакетний менеджер `apt-get`.
- **Для Arch Linux та Manjaro:** скрипт автоматично перемикається на використання `pacman`. Крім того, він бере до уваги специфіку цих дистрибутивів: наприклад, самостійно активує сервіс Docker через `systemctl enable --now docker` (оскільки в Arch Linux демони не стартують автоматично після встановлення) та використовує адаптовані назви пакетів (`python-django`, `python-virtualenv` замість `python3-venv` тощо).

## Як запустити:

1. Надайте скрипту права на виконання:
```bash
chmod u+x install_dev_tools.sh
```

2. Запустіть скрипт (може знадобитися ввести пароль для `sudo`):
```bash
./install_dev_tools.sh
```

3. Після успішного завершення роботи скрипта ви можете самостійно перевірити версії інструментів:
```bash
docker --version
docker compose version
python3 --version
python3 -m django --version
```
